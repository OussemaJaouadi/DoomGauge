# Cognitive and communication preferences

- User-reported auADHD; limited reading capacity during headaches.

- Lead with visuals, exact numbers and short bullets.
- Keep choices visible; avoid nested tabs and hidden dropdown options.
- Preserve platform colors as a visual map.
- Prefer inspection dialogs over navigation.
- Keep alignment and number widths stable.
- No streaks, confetti, moralizing or guilt.
- Use urgency sparingly; follow current [color roles](DESIGN.md).

| Observation | Supported interpretation |
| --- | --- |
| Active time | Recorded foreground playback |
| Quick skips | Completed visits below three active seconds |
| Returns | Session gaps with observed follow-up |
| Repeated windows | Descriptive patterns in eligible history |

- No inference of intent, dopamine levels, compulsion or diagnosis.
- Label interpretations separately from recorded facts.
