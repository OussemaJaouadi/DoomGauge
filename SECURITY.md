# Security Policy

## Scope
DoomGauge is a **local-first** extension: it stores all data in your browser
(IndexedDB) and transmits nothing to any server. There is no backend in v1.

## Supported Versions
| Version | Supported |
| ------- | --------- |
| v1.x    | yes       |

## Reporting a Vulnerability
If you discover a vulnerability (e.g. unintended data exposure, injection in
the dashboard, excessive permissions), report it privately via GitHub
Security Advisories (enabled on this repo). Please do not open public issues
for security reports. We aim to acknowledge within 7 days.
